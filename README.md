# IT Wing SDK for Android

IT Wing SDK v1.51 is a corrective drop-in Android library update for v1.48+ applications. It restores the approved v1.49 ad presentation while retaining v1.50 suppression behavior. No host integration changes are required. See [CHANGELOG.md](CHANGELOG.md) for release notes and the validation boundary.

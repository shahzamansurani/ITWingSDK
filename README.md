# IT Wing SDK for Android

IT Wing SDK v1.52.1 is a drop-in Android library update for v1.48+ applications. It retains the approved ad presentation and AdMob-first delivery, maps generic admin palette colors, and restores the established Google Mobile Ads startup sequence. See [CHANGELOG.md](CHANGELOG.md) for release notes.

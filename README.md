## v1.60

```kotlin
implementation("com.github.shahzamansurani:ITWingSDK:v1.60")
```

This release retains the approved v1.57 runtime behavior and adds the
collapsible top/bottom banner and first-touch inline recovery fixes. It also
adds safe placement-format handling, nonfatal interstitial preloading, and the
universal XML `ITWingAdView` placement renderer. Existing normal banner,
Native, interstitial, App Open, fallback, shimmer, flow, billing, and
configuration behavior is preserved.

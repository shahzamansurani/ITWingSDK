# IT Wing SDK for Android

IT Wing SDK v1.52 is a drop-in Android library update for v1.48+ applications. It retains the approved ad presentation and AdMob-first delivery while correcting generic admin palette mapping and reducing first-launch ad initialization races. No host integration changes are required. See [CHANGELOG.md](CHANGELOG.md) for release notes.
